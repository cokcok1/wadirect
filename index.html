常見問題與原理

為什麼不需要儲存聯絡人？

本工具利用 WhatsApp 官方提供的 API 連結協定（`wa.me`），直接開啟對話，不會讀取或修改你手機內的通訊錄。

我的資料安全嗎？

100% 安全！所有輸入的號碼與草稿只會保存在你的本地瀏覽器（LocalStorage）中，絕不會上傳到任何伺服器。

電腦版點樣使用？

在電腦點擊會自動開啟 WhatsApp 網頁版或桌面版。你亦可以生成 QR Code 用手機相機直接掃描開啟。
