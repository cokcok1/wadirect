常見問題與運作原理

為什麼不用儲存電話？

本工具使用 WhatsApp 官方 API 深度連結 (`wa.me`) 技術，直接傳送指令給 WhatsApp 開啟對話，完全不存取或修改你的通訊錄。

會否洩漏隱私資料？

100% 安全！所有發送紀錄與文字均只儲存在你的瀏覽器本機 (LocalStorage) 中，沒有任何後端伺服器收集你的資料。

電腦版如何配合使用？

在電腦上點擊會自動打開 WhatsApp Web 或 Desktop 應用程式；亦可點擊「產生 QR Code」讓手機相機直接掃碼開啟。
